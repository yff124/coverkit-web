# coverkit web

打开即用的封面生成器。**输入一个标题，出齐 10 个平台的封面尺寸** —— 小红书、公众号、视频号、抖音、知乎、B 站、微博、YouTube、X。

纯前端单文件，**不联网、不上传、不装任何东西**。标题不会离开你的设备，可以断网使用。

> 这是 [coverkit](https://github.com/yff124/coverkit)（Python 命令行版）的浏览器版本。
> 同一个尺寸表、同一套配色。差别在于：命令行版能接进脚本批量跑，浏览器版是双击就能用的图形界面。

---

## 为什么需要它

同一篇文章要发到五个平台，就要改五次封面尺寸。用设计软件一个个改太慢；**让 AI 生图，标题里的中文必糊** —— 笔画密集、字形复杂，扩散模型画中文字几乎一定会出伪字。

所以走第三条路：**用代码画**。文字是文字，不是被"画"出来的图案。

## 它处理了什么

| 问题 | 处理方式 |
|---|---|
| 中文折行位置不对 | 按**标点**断行，而不是按像素硬切 |
| 标点被甩到行首 | 实现**行首禁则**：`，。、；：？！）】》」` 这类字符被拉回上一行末尾 |
| 开引号掉在行尾 | 实现**行尾禁则**：`（【《「『` 推到下一行 |
| 标题太长溢出画布 | **自适应字号**：从起始字号逐档递减，找到能放进给定区域的最大字号 |
| 英文单词被拆断 | 连续的半角字符（单词 / 数字 / URL）作为一个整体参与折行 |

## 用法

打开 `index.html` 就行。要部署给别人用：

```bash
# 直接扔到任意静态托管（GitHub Pages / Netlify / 对象存储）
# 整个项目就一个 html 文件，没有依赖、没有构建步骤
```

填三个字段就够了：

- **主标题**（必填）—— 换行会被尊重
- **副标题**（可选）
- **栏目标签 / 底部小字**（可选）

选主题、选版式，然后逐张下载或一次下载全部。

## 主题

`midnight`（深蓝）· `paper`（暖白）· `forest`（墨绿）· `sunset`（紫橙）· `ink`（墨金）

版式三选一：`split`（左侧色带）· `gradient`（纯渐变）· `solid`（纯色）

配色定义在 `THEMES` 对象里，加一套主题就是加一个字段。

## 已知边界

- **字体依赖系统**。用 `PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans SC` 的字体栈，各平台字形会有细微差异（这是浏览器的正常行为）。
- **不做图片背景**。目前只出纯色/渐变底 + 文字。要图片底，用命令行版接入任意图片源。
- **导出是逐张触发**。浏览器会串行弹保存框。「下载全部」会给每次下载间隔 320ms，避免被浏览器拦掉。
